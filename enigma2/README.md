# OSCam Stability Info for Enigma2 / OpenATV

This optional native Enigma2 plugin displays OSCam Stability service status, version,
the selected softcam (when exposed through /etc/init.d/softcam) and the local ECM
summary from /tmp/ecm.info. It is **read-only** and does not change readers, ECM
settings, passwords, or the active softcam.

Install from the receiver's root shell:

```sh
wget -O /tmp/install-oscam-info.sh https://raw.githubusercontent.com/Baniak88/oscam-stabilny/main/enigma2/install-info.sh && sh /tmp/install-oscam-info.sh
```

Then restart **Enigma2 GUI** from the receiver's restart menu and open
**Plugins > OSCam Stability Info**. The information is refreshed every 5 seconds.

This plugin uses the existing `/var/run/oscam-stability/oscam.pid` and
`/usr/lib/oscam-stability` paths from OSCam Stability 1.3.0.
The optional `/tmp/ecm.info` file is generated by the local dvbapi integration
when supported; if it is missing, the plugin explains that ECM data is unavailable.

Compatibility notes:
- Enigma2 must include Python 3 and the standard Screen/ScrollLabel APIs.
- Different OpenATV builds may expose the selected softcam through a different
  mechanism. The screen reports 'not selected' rather than guessing.
- This is a plugin source installation, not an IPK upgrade. No OSCam binary changes.
- If Enigma2 does not show the plugin after GUI restart, inspect Enigma2 startup logs
  for import errors. Physical-device compatibility has not yet been tested.
